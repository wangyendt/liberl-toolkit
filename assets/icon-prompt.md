```text
Use case: logo-brand
Asset type: Windows desktop application icon for Liberl Toolkit, a Chinese-language RPG trainer.
Primary request: Create one beautiful, polished, immediately recognizable standalone app icon, with a bold silhouette that remains readable at 32 pixels.
Subject: An original circular orbment-inspired compass instrument: a luminous sky-blue crystal core enclosed in a thick deep-navy circular mechanism with a few elegant warm brass accents. A single bold, swept wing shape integrated into the mechanism evokes sky, exploration, and Liberl. It should feel like a finely crafted instrument, both adventure and utility.
Style: premium stylized enamel and machined-metal emblem, restrained dimensional shading, clean broad forms, crisp edges. Sophisticated and friendly desktop software identity.
Palette: deep navy #203e56, sky blue #327caa and pale cyan light, small warm brass highlights.
Composition: one centered unified emblem filling about 84 percent of a square canvas, front-facing, balanced, generous small transparent margin. No pedestal or external shadow. Clear silhouette with thick shapes; no tiny gear teeth.
Background: genuinely transparent outside the emblem.
Text: none.
Avoid: words, letters, numerals, official game logos, copied character art, photorealism, intricate linework, disconnected floating objects, excessive effects, rainbow RGB, fake checkerboard background.
```
